# Watermark

`logo/wordmark-watermark.svg` — the quiet wordmark (no dot, 40% opacity,
`currentColor`).

- **Covers**: top-left, paper color, height ≈ 7% of cover side (the cover
  system uses the full-color brand row instead when space allows).
- **Share pages**: footer, ink color, with "made with oto" if copy is needed.
- **音 seal as watermark**: share pages only, bottom-right, ≥16px, ink at 25%.

Never watermark inside the iOS app chrome — the app is already the brand.
