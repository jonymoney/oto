# Typography

- **Clash Display Semibold (600)** — wordmark, mastheads, player titles,
  editorial empty-states. Never numerals, never body text.
  License: Fontshare ITF-FFL (free commercial, bundling OK, no file
  modification/redistribution). Download: fontshare.com/fonts/clash-display.
- **SF Pro** — all iOS UI (system default; free on Apple platforms only).
  Timecodes via `.monospacedDigit()`.
- **Instrument Sans** (OFL, Google Fonts) — web/share pages UI + body.
  Timecodes via `font-variant-numeric: tabular-nums`.
- **Zen Kaku Gothic New Medium** (OFL) — the 音 seal and kanji micro-labels
  only. Never running text, never below 16px.

Rules: timecodes are ink_muted + tabular + UI face — never display type, never
accent. Eyebrows: UI face 700, uppercase, ~0.22em tracking, accent_text color.
Mastheads carry a 2px ink rule below.
